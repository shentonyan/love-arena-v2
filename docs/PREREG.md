## 研究问题
RQ1：本地 LLM 判官能否在 PoL 爱语改写的各维度上替代人工判断？
RQ2：三个本地模型的爱语改写质量是否可区分？
RQ3：判官是否偏爱自己的改写（自偏好）？

## 假设与判定规则
| 编号 | 假设 | 支持的条件 | 不支持（负结果） |
|---|---|---|---|
| H1 | 至少一个判官在每个核心维度上有效 | Score 维度 Spearman ρ ≥ 0.40；Noul 维度 AUC ≥ 0.70 | 任一核心维度无判官达标 → 不计算 J，不产出偏好对 |
| H2 | 判官存在自偏好 | β_self 的 95% CI 不含 0，方向为“有利于自己” | CI 含 0 |
| H3 | 模型间 J 存在差异 | 两两差值的 95% CI 不含 0 | CI 含 0 → 报告“无法区分”，不做排名 |

参照上限：两位标注者间的 Krippendorff α。若某维度 α < 0.40，先修订 CODEBOOK 中该维度的定义，不评判判官。

## 设计
- 材料：`data/sentences.txt`，60 句（中文 50，英文 10）；每句每模型采样 2 次，温度 0.7，固定种子。
- 选手与判官：gemma4:26b、qwen2.5:7b、llama3.1:8b，全交叉判定（含自评）。
- 维度：核心维度为 hate_residue、honesty、fluency，组成主指标 J = 去恨语 × 诚实 × 流畅；PoL 次要维度为 equal_connection、condescending，单独报告。
- 去偏：量表正序、倒序各问一次；陈述句和否定句各问一次。
- 校准：每个判官在 honesty、condescending 上单独做 Platt 校准，用留一法报告 Brier。
- 校正：用 y = 选手 + 判官 + 句子 + β_self·自评 的线性模型扣除判官宽严与自偏好。
- 不确定性：按句子 cluster bootstrap 2000 次，报告 95% CI。
- 人工金标准：按模型分层随机抽 42 条盲评样本（隐去模型名，两人条目顺序不同），两位标注者独立标注。

## 主要局限（事先声明）
- 42 条验证样本只能检出较强的一致性；ρ 的 95% CI 宽约 ±0.25。
- 判官与选手是同一批模型，自偏好只能估计、扣除，无法彻底消除。
- 线性校正是多面 Rasch 模型的近似。
- “恨语”是 PoL 的概念，不等于去毒研究里的 toxicity，也不等于 hate speech。本实验借用的是那些研究的方法，不是它们的概念。
- 结果是假设生成性质，不能推广到真实人群。
